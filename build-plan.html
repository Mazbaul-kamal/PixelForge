PixelForge — ধাপে ধাপে বিল্ড প্রম্পট

Photopea-ধাঁচের ব্রাউজার ইমেজ এডিটর বানানোর ২৬টি প্রম্পট। প্রতিটা ধাপে একটা করে টুল বা সিস্টেম — সম্পূর্ণ কাজ করা অবস্থায়, আধা-বানানো কিছু নয়।

স্ট্যাক TypeScript + Vite ইঞ্জিন Canvas 2D → WebGL ধাপ 26 আনুমানিক ৮–১২ সপ্তাহ
০ / ২৬

কীভাবে ব্যবহার করবেন

  1. নতুন চ্যাট বা Claude Code সেশন শুরুর সময় একবার প্রজেক্ট কনটেক্সট (ধাপ ০) পেস্ট করুন।
  2. এরপর এক সেশনে একটাই ধাপের প্রম্পট দিন। একসাথে দুটো দিলে দুটোই আধা হয়।
  3. প্রতি ধাপ শেষে নিজে ব্রাউজারে হাতে-কলমে টেস্ট করুন — নিচের চেকলিস্ট মিলিয়ে।
  4. কাজ করলে git commit করুন, তারপর ঘরটা টিক দিন। না করলে পরের ধাপে যাবেন না — ভিত্তি নড়বড়ে থাকলে ১৫ নম্বর ধাপে এসে সব ভাঙবে।

প্রম্পটগুলো ইংরেজিতে রাখা হয়েছে ইচ্ছাকৃতভাবে — ভেরিয়েবল, ইন্টারফেস আর API-এর নাম ইংরেজি, তাই কোডিং এজেন্ট কম ভুল করে। ব্যাখ্যা আর চেকলিস্ট বাংলায়।

একটা পরামর্শ: ধাপ ১০ (সিলেকশন মাস্ক ইঞ্জিন) আর ধাপ ২৬ (টাইলিং) — এই দুটোই সবচেয়ে বেশি রিরাইট ঘটায় যদি আগে ঠিকভাবে ডিজাইন না করেন। ১০ নম্বরে সিলেকশনকে শুরু থেকেই মাস্ক হিসেবে বানাবেন, rectangle হিসেবে নয়। পরে ঠিক করতে গেলে প্রতিটা টুল ছুঁতে হবে।
